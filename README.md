One funny line answering a prompt — the excuse a robot vacuum gives after eating a sock — a [make.fun](https://make.fun) bounty entry by [@dizellacapital](https://make.fun/r/qxacafna).

## The line

> The sock started it. I finished it. The dustbin is my witness.

62 characters. The vacuum pleads its case like a defendant in court: the sock started the fight, the vacuum merely finished it, and the punchline reframes its own dustbin as the star witness. Deadpan, three beats, every word working.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the line is 1–200 characters, a single line, and not only whitespace, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads it back to verify the write.
